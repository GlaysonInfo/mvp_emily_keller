# Seleção de Sensor de Pressão

Como a pressão pode chegar a 100 bar, sensor 0–10 bar não é adequado para monitoramento real.

Recomendação do piloto:

```text
0–250 bar
IO-Link
24 Vcc
IP67+
conexão compatível com adaptador em T
```

O sensor 0–250 bar permite:
- medir pressão normal;
- medir picos;
- detectar obstrução;
- evitar saturação;
- formar baseline confiável.
