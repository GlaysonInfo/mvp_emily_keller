# Modelo de Relatório — Lubrificação

Conteúdo recomendado:
- período analisado;
- quantidade de ciclos;
- saídas monitoradas;
- saídas com alerta;
- maior pressão registrada;
- baixa pressão por saída;
- alta pressão por saída;
- alívio lento;
- reincidência;
- recomendação da IA;
- ações tomadas.
