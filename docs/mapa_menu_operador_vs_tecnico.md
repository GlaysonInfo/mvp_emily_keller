# Mapa de Menu — Operador x Técnico

## Modo Operador

| Menu | Para que serve |
|---|---|
| Painel da Planta | Ver situação geral e prioridades |
| Equipamento | Ver detalhes do equipamento selecionado |
| Lubrificação | Ver pressão por saída de graxa |
| Alertas | Ver e tratar alertas |
| Relatórios | Exportar informações |
| Ajuda | Guia rápido de uso |

## Modo Técnico

Inclui todas as páginas existentes:
Visão Geral, Detalhe, Inteligência, Lubrificação, Configuração de Campo, Alertas, Matriz, Outbox, Relatórios, Configurações e Teste ponta a ponta.
