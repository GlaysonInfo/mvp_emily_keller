# Checklist de Implantação em Campo

## Mecânica
- [ ] Confirmar rosca dos manômetros.
- [ ] Definir conexão em T.
- [ ] Manter manômetros físicos.
- [ ] Fixar sensores sem esforço mecânico na linha.

## Sensores
- [ ] Faixa recomendada 0–250 bar.
- [ ] Alimentação 24 Vcc.
- [ ] IO-Link ou 4–20 mA conforme gateway.
- [ ] Proteção IP67 ou superior.

## Gateway
- [ ] Definir modelo real.
- [ ] Mapear portas.
- [ ] Validar leitura por tag.
- [ ] Confirmar protocolo disponível.

## Sistema
- [ ] `/grease/health` responde.
- [ ] `/grease/ingest` recebe payload.
- [ ] Dashboard mostra ciclo.
- [ ] Alertas são gerados.
- [ ] IA gera recomendação.
